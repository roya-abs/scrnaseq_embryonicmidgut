# scRNAseq of Drosophila Embryonic Midgut

This repository contains the computational workflow, analysis notebooks, software environment files, and custom scripts used for the single-cell RNA-seq analysis of Drosophila embryonic midgut development.

The analyses support the study:

Distinct Roles of the Intrinsic Transcriptional Program and Extrinsic Tissue Cues in the Mesenchymal-Epithelial Transition in Embryonic Midgut Development

R. Abbaszade, G. Salinas, F. Wolf, J. Grosshans

## Data availability

Raw sequencing data and processed single-cell gene expression matrices have been deposited in the NCBI Gene Expression Omnibus (GEO) under the accession number GSE343179. 

Large data files are not stored directly in this GitHub repository. 

## Reproducibility notes

The repository is intended to document the full computational workflow used in the study. Some notebooks require large intermediate files that are available through GEO or generated by earlier steps of the workflow. Paths to input and output files may need to be adjusted depending on the local directory structure.

Random seeds were set where applicable. However, minor differences in results may occur depending on software versions, package dependencies, and computational environment.
